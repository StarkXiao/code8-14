# 海底光缆施工与渔船避让协同系统（原型）

将**海缆施工窗口/安全廊道**与**渔船作业区/动态船位**在同一海图上叠加，进行时空冲突检测，并在冲突发生前向**施工方与渔船方双向预警**。

![架构](https://img.shields.io/badge/stack-Node.js%20%7C%20Leaflet%20%7C%20零运行时依赖-blue)

## 快速开始

```bash
npm start
# 打开 http://localhost:3000
```

- 无需 `npm install`（后端仅使用 Node 内置模块）
- 前端通过 CDN 加载 Leaflet 1.9.4，海图底图为 CARTO dark 瓦片（需联网）

## 功能

### 1. 空间叠加（地图）
- 🔴 红色实线：两条海缆设计路由（舟山—洋山主干、岱山支线）
- 🔵 蓝色虚线廊道：路由两侧各 500 m 施工安全廊道（实时由路径偏移生成）
- 🟢/🟡/🔴 多边形：三个渔船作业区，颜色随冲突状态实时变化
- ▲ 渔船（含环线作业、航行、漂航、在港四种运动模式，带航迹尾迹）
- ◆ 施工船：仅在施工窗口内出现在路由上，按窗口时间匀速往返

### 2. 时空冲突检测（`lib/conflict.js`）
- **作业区 × 施工窗口**：几何相交 + 时间窗重叠两个条件同时满足才构成冲突
  - 作业区与路由直接重叠 / 侵入安全廊道 → 🔴 严重
  - 距路由 1 海里预警圈内 → 🟡 预警
  - 时间轴上以红色段标出重叠冲突期
- **单船动态接近**：仅在施工窗口（含提前 15 分钟）内评估
  - 进入 500 m 廊道 → 严重；1500 m / 3000 m → 两级预警
  - 按航速估算到达路由的时间（ETA）

### 3. 双向预警
每条冲突同时生成两条可直接下发的信息：
- 📡 **致施工方**：渔船编队、艘数、VHF 频道/电话、协调建议
- 🐟 **致渔船方**：施工船名、施工内容、避让动作、VHF 守听要求

### 4. 预警生命周期
`提前预告（倒计时） → 冲突生效 → 等级升级（动态接近） → 预警解除`
事件流全部记录在「预警记录」页，地图脉冲圈随等级变化。

### 5. 推演控制
- 仿真从当日 **02:30** 开始，覆盖 03:00 早窗口至 18:00 下午窗口
- 倍速切换：15× / 60× / 300× / 900×，支持一键重置

## 场景设计（舟山以东海域）

| 对象 | 空间关系 | 时间关系 | 预期事件 |
|---|---|---|---|
| Z1 岱衢洋帆张网区 × P1 主干 | 作业区穿越路由 | 04:00–09:00 与 03:00–06:30 重叠 | 02:30 即提前预警，04:00 生效，06:30 解除 |
| Z2 灰鳖洋拖网区 × P2 支线 | 穿越路由；边缘侵入 P1 廊道 | 12:00–16:30 与 13:00/13:30 窗口重叠 | 13:00、13:30 先后两次严重冲突 |
| Z3 双合门流刺网区 | 距路由 >15 km | 夜间作业 | 无冲突（对照） |
| B1 渔船 | 沿环线反复穿越 P1 | — | 预警随进出廊道反复升级/解除 |
| B2 渔船 | 朝 P2 航线航行 | — | 动态接近预警 |
| B4 渔船 | 在港 | — | 不参与检测 |

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/base` | 项目、廊道、作业区等静态数据 |
| GET | `/api/state` | 当前仿真时刻 + 全部冲突 + 事件流 |
| GET | `/api/events` | 预警事件记录 |
| POST | `/api/speed?x=60` | 设置推演倍速（15/60/300/900） |
| POST | `/api/reset` | 重置仿真 |

## 目录结构

```
server.js            零依赖 HTTP 服务：场景推演 + 检测调度 + 事件流
lib/geo.js           地理计算：距离/方位/廊道偏移/多边形相交
lib/scenario.js      模拟场景数据（海缆、作业区、渔船）
lib/conflict.js      时空冲突检测规则
lib/simulator.js     船舶运动与加速时钟模拟
public/              Leaflet 前端（地图叠加 / 预警卡片 / 时间轴）
```

## 说明与局限

原型用于演示协同机制，工程化时建议替换/补充：

- 渔船动态接入真实 **AIS 基站 / 北斗船位** 数据流（本原型为运动学模拟）
- 廊道几何在大范围海域应改用测地线缓冲与投影坐标（当前为局部等距圆柱近似）
- 预警下发对接 **VHF 数字选呼（DSC）、北斗短报文、海事 SMS / 船载终端**
- 增加气象/海流约束、施工船操纵限制与渔船网具扫海范围
- 冲突协商闭环：渔船编队确认避让、施工方调整窗口后的状态回写
