# 海底光缆施工 · 渔船避让协同系统

将**施工窗口**（海缆路由段 + 安全缓冲带 + 时间窗）与**渔船作业区**（渔区边界 + 作业时段）
在时空两个维度上叠加分析，发现冲突时**提前向施工侧与渔业侧双向预警**。

零第三方依赖（纯 Python 标准库 + 原生 Canvas 前端），离线可运行。

## 快速开始

```bash
cd cable-guard
python3 server.py            # 默认 8000 端口
# 打开 http://localhost:8000
```

```bash
python3 test_engine.py       # 运行 24 项引擎单元测试
```

## 功能

| 模块 | 说明 |
|---|---|
| 时空叠加分析 | 空间：施工路径缓冲带 × 渔区（多边形/圆形）求交；时间：窗口重叠区间计算 |
| 三级预警 | 红 `<24h` / 橙 `24~72h` / 黄 `>72h`，按距冲突开始的提前量分级 |
| 双向预警 | 每起冲突生成施工侧、渔业侧两条报文，含避让建议（改道/航行警告/VHF16 守听等） |
| 海图态势 | Canvas 海图：路由、缓冲带、渔区、AIS 船位（匀速外推），闯入缓冲带的渔船变红 |
| 时间轴 | 拖动/播放，复盘或预演任意时刻的施工-渔船态势 |
| what-if 推演 | `POST /api/windows` 插入临时施工窗口，系统即时重算冲突与预警 |

## API

```
GET  /api/overview    场景全量 + 冲突 + 预警 + 危险船位
GET  /api/conflicts   冲突列表（按开始时间排序）
GET  /api/alerts      双向预警报文
POST /api/windows     新增/覆盖施工窗口，返回重算结果
```

新增窗口示例：

```bash
curl -X POST http://localhost:8000/api/windows -d '{
  "id":"WX","name":"应急抢修","vessel":"启帆9","activity":"打捞维修",
  "contractor":"某海缆工程公司","path":[[122.28,29.66],[122.42,29.78]],
  "buffer_km":2,"start":"2026-09-21T08:00","end":"2026-09-22T08:00"}'
```

## 数据模型

- **施工窗口**：路由折点 `path`、安全缓冲半径 `buffer_km`、`start/end`、施工船、作业类型
- **渔船作业区**：多边形 `polygon` 或圆形 `center+radius_km`、作业时段、船队与艘数
- **AIS 船位**：船位 + 航速航向 + 时间戳，支持任意时刻匀速外推

## 文件结构

```
cable-guard/
├── engine.py            时空冲突检测引擎（几何/时间/预警生成）
├── sample_data.py       示例场景：东海舟山外海风电缆工程（相对当前时间生成）
├── server.py            REST API + 静态服务（标准库）
├── static/index.html    海图 + 时间轴 + 预警面板（零依赖）
└── test_engine.py       引擎单元测试
```

## 生产化扩展方向

- 数据源接入：AIS 实时报文、渔政船位系统、施工船 DP 位置、航行警告（NAVTEX）
- 预警推送：对接短信/甚高频自动播报/渔政平台与施工方调度系统
- 更精细的缓冲带：按施工船速、埋设犁姿态、水深分段设置缓冲半径
- 持久化：窗口/渔区/预警记录入库，支持冲突处置闭环（确认、改期、解除）
